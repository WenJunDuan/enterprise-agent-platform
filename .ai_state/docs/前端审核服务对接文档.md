# 前端审核服务对接文档

前端接这个审核能力，只需要做 4 件事：

1. 带 token
2. 提交表单和文件
3. 轮询任务状态
4. 获取最终审核结果

---

## 1. 前端会用到几个接口

前端主流程只需要 `3` 个核心接口，外加 `1` 个可选接口。

### 核心接口

1. `POST /audit/submit`
2. `GET /audit/tasks/{request_id}`
3. `GET /audit/tasks/{request_id}/result`

### 可选接口

4. `GET /results/{request_id}`

说明：

- 页面正常展示结果时，只用前面 3 个接口就够了
- `GET /results/{request_id}` 只在你想看完整归档外壳时再用

---

## 2. 前端第一步：请求头怎么带

所有接口都要带：

```http
Authorization: Bearer <token>
```

本地key目前是：

```http
Authorization: Bearer sk-wdsddferfer1243HJGTIOJlL809jjl90dasdn9
```

前端代码里不要把这个值写死到生产环境。

---

## 3. 前端第二步：怎么提交数据

前端正式接入时，统一调用：

```http
POST /audit/submit
```

并且使用：

```http
Content-Type: multipart/form-data
```

也就是说，前端要用 `FormData` 提交，而不是普通 JSON。

---

## 4. 提交时一共要传哪些字段

前端提交时需要传 3 类字段：

- `mode`
- `form_json`
- `files`

### 4.1 `mode`

固定传：

```text
upload
```

### 4.2 `form_json`

这是一个 JSON 字符串，不是对象本身。

前端要先组对象，再 `JSON.stringify()`：

```ts
fd.append("form_json", JSON.stringify(formObject));
```

### 4.3 `files`

一个或多个附件，字段名统一都是 `files`。

多文件时重复 append：

```ts
fd.append("files", file1);
fd.append("files", file2);
fd.append("files", file3);
```

---

## 5. `form_json` 字段格式是什么

### 5.1 必填字段

当前后端只强制要求这 `3` 个字段：

- `case_id`
- `applicant_name`
- `expense_type`

### 5.2 推荐字段

虽然不是强制，但前端实际接入建议一起传：

- `department`
- `expense_category`
- `biz_date`
- `meal_period`
- `participants_total`
- `internal_participants`
- `client_count`
- `city`
- `description`
- `business_purpose`
- `currency`
- `notes`

### 5.3 字段类型建议

| 字段名                  | 类型     | 是否必填 | 说明                             |
| ----------------------- | -------- | -------- | -------------------------------- |
| `case_id`               | `string` | 是       | 业务单号或前端生成的唯一编号     |
| `applicant_name`        | `string` | 是       | 报销申请人姓名                   |
| `expense_type`          | `string` | 是       | 费用大类，如“业务招待”“差旅报销” |
| `department`            | `string` | 否       | 所属部门                         |
| `expense_category`      | `string` | 否       | 费用子类，如“餐饮招待”“交通费”   |
| `biz_date`              | `string` | 否       | 业务日期，建议 `YYYY-MM-DD`      |
| `meal_period`           | `string` | 否       | 如“中午”“晚上”                   |
| `participants_total`    | `number` | 否       | 总参与人数                       |
| `internal_participants` | `number` | 否       | 内部参与人数                     |
| `client_count`          | `number` | 否       | 客户人数                         |
| `city`                  | `string` | 否       | 业务发生城市                     |
| `description`           | `string` | 否       | 业务描述                         |
| `business_purpose`      | `string` | 否       | 业务目的                         |
| `currency`              | `string` | 否       | 币种，通常传 `CNY`               |
| `notes`                 | `string` | 否       | 备注                             |

## 6. 文件怎么加

前端上传附件时，字段名统一使用 `files`。

示例：

```ts
for (const file of files) {
  fd.append("files", file);
}
```

### 6.1 当前支持的文件类型

- `.pdf`
- `.png`
- `.jpg`
- `.jpeg`
- `.webp`

### 6.2 当前限制

- 不允许空文件
- 单个文件大小不能超过后端配置的 `MAX_UPLOAD_FILE_BYTES`

如果前端上传了不支持的文件，后端会返回 `400 Unsupported file type`。

## 8. 提交成功后会返回什么

成功后返回：

```json
{
  "request_id": "faf62e3a-fa35-4d47-acd6-93b74190fe46",
  "status": "accepted",
  "mode": "upload",
  "task_status_url": "/audit/tasks/faf62e3a-fa35-4d47-acd6-93b74190fe46",
  "result_url": "/results/faf62e3a-fa35-4d47-acd6-93b74190fe46"
}
```

前端先重点拿这 2 个字段：

- `request_id`
- `status`

注意：

- `accepted` 只表示任务已经创建
- 不表示审核完成

所以提交成功后，前端下一步不是展示结果，而是去轮询状态。

## 9. 前端怎么查询状态

接口：

```http
GET /audit/tasks/{request_id}
```

示例代码：

```ts
const taskRes = await fetch(`/audit/tasks/${requestId}`, {
  headers: {
    Authorization: "Bearer sk-default",
  },
});

const task = await taskRes.json();
```

返回示例：

```json
{
  "request_id": "faf62e3a-fa35-4d47-acd6-93b74190fe46",
  "status": "running",
  "mode": "upload",
  "source_mode": "upload",
  "case_path": "data/submissions/faf62e3a-fa35-4d47-acd6-93b74190fe46",
  "claim_id": null,
  "result_file": null,
  "error_detail": null,
  "progress_message": "正在调用 Claude 审核",
  "submitted_at": "2026-03-31T09:27:31.691389+00:00",
  "started_at": "2026-03-31T09:27:32.100000+00:00",
  "finished_at": null,
  "updated_at": "2026-03-31T09:27:31.691389+00:00"
}
```

### 9.1 状态值只有这 4 个

- `accepted`
- `running`
- `completed`
- `failed`

### 9.2 前端处理建议

- `accepted`
  - 继续轮询
- `running`
  - 继续轮询
- `completed`
  - 去查结果接口
- `failed`
  - 展示 `error_detail`

### 9.3 推荐轮询代码

```ts
async function pollAuditTask(requestId: string) {
  while (true) {
    const res = await fetch(`/audit/tasks/${requestId}`, {
      headers: {
        Authorization: "Bearer sk-default",
      },
    });

    const task = await res.json();

    if (task.status === "completed" || task.status === "failed") {
      return task;
    }

    await new Promise((resolve) => setTimeout(resolve, 2000));
  }
}
```

## 10. 前端怎么拿最终结果

接口：

```http
GET /audit/tasks/{request_id}/result
```

示例代码：

```ts
const resultRes = await fetch(`/audit/tasks/${requestId}/result`, {
  headers: {
    Authorization: "Bearer sk-default",
  },
});

const audit = await resultRes.json();
```

返回示例：

{

## 11. 前端最简接入顺序

前端真正要写的流程就是：

1. 用户填写表单
2. 用户选择一个或多个文件
3. 前端组装 `FormData`
4. 调 `POST /audit/submit`
5. 拿到 `request_id`
6. 轮询 `GET /audit/tasks/{request_id}`
7. 当状态变成 `completed` 时，调 `GET /audit/tasks/{request_id}/result`
8. 把结果渲染到页面

---

## 12. 常见错误

### 提交阶段

- `401 Invalid API key`
  - token 不对
- `400 Missing required form fields: ...`
  - 缺必填字段
- `400 Invalid form_json`
  - `form_json` 不是合法 JSON
- `400 form_json must decode to a JSON object`
  - `form_json` 不是对象
- `400 At least one file is required for upload mode`
  - 没有上传任何文件
- `400 Unsupported file type`
  - 文件扩展名不支持
- `400 Uploaded file cannot be empty`
  - 上传了空文件

### 查询阶段

- `404 Audit task not found`
  - `request_id` 不存在
- `409 Audit task is not completed yet`
  - 任务还没完成，继续轮询
- `404 Audit result not found`
  - 结果不存在，提示后端排查

---

## 13. 一页总结

- 请求头带 `Authorization: Bearer <token>`
- 提交接口用 `POST /audit/submit`
- 用 `FormData`
- `mode=upload`
- `form_json` 要 `JSON.stringify()`
- 附件字段名统一是 `files`
- 提交后拿 `request_id`
- 轮询状态
- 完成后取结果

```js
const form = new FormData();
form.append("mode", "upload");
form.append(
  "form_json",
  JSON.stringify({
    case_id: "EXP-2026-000123",
    applicant_name: "张三",
    expense_type: "差旅报销",
    department: "销售部",
    expense_category: "交通费",
    biz_date: "2026-04-01",
    total_amount: 1386.5,
    currency: "CNY",
    city: "上海",
    business_purpose: "客户拜访",
  }),
);
form.append("files", file1);
form.append("files", file2);
form.append("files", file3);

const res = await fetch("http://127.0.0.1:8000/audit/submit", {
  method: "POST",
  headers: { Authorization: "Bearer sk-default" },
  body: form,
});
const data = await res.json();
```
