## 三、纠偏令（三条，核心）

### 纠偏令一 · Agency 薄实验前移（新增 Phase A，插队于 D1/D2 之后、P2/P3 定形之前）

**论证**（全部来自你们自己的数据）：

- 6 项 `evidence_unresolved` 的材料"投标文件里明明有"（handoff 五节）；
- 检索错位实测：投标报价(82分)拿到招标层废标条款、施工组织设计(6分)拿到 48 token 标题行、业绩块记账到安全生产许可证名下（plan D2）；
- golden case 的 D1 缺陷（声明函↔报价表跨文件矛盾）对**任何**按项检索都是结构盲区——没有单项查询会同时召回这两处。回归闸跑通后此条会被数字证实。

会话前检索永远在"不知道什么重要"时决定模型能看什么；参照链路的全部 P0 发现都来自"看到A才去查B"的运行时因果链。**结论：agency 与 P4 拆调用解耦**——agency 是小改动（落盘 + 工具面 + 三句指令），不是"最大工程量"的一部分。

**A.1 语料落盘**（v1 Phase 1 的最小子集）

- `doc_pipeline` 产出底稿时同步落盘 `data/tenders/<case>/corpus/`：每源文件一个带页锚的 `.txt`（底稿原样，不二次加工）+ `manifest.json`（每页 `{page, chars, kind: text|image|blank}`，复用现有空白页判定）；
- PDF 入管线前置 `qpdf --check`，损坏先修复（参照实跑第一发现：损坏文件页数报 5 实为 400）。

**A.2 评标调用工具面开关**

- `TENDER_AGENCY=1` 时 `DRAFT_INJECTED_TOOLS` 扩为 `["Bash","Grep","Read"]`；默认 0，零行为变更；
- Grep/Read 路径经 PreToolUse hook 钉死到本案 `corpus/` 目录（仿 ocr-page hook 形态）；单次 Read ≤200 行；`max_turns` 维持现值；
- 初始注入**不变**（检索一次做完的证据块照旧），命令追加三句：初始片段头保留"未注入≠未提供"；可对 corpus 目录 grep 定位后按行区间 Read 补证；引用页码取所读文本中的页锚。

**A.3 度量与验收**

- 对照组 = 当前 `5ccbb361` 形态（TENDER_AGENCY=0），实验组 =1；case-zj-live + YD case 各 `--repeat 3`；
- 指标：回归闸四指标 + 新增两列（补证 Grep/Read 调用次数、补证后新判出项数）；
- 通过线：`evidence_unresolved`（剔除 cross_bid/live_event）显著下降**或**跨文件缺陷召回提升，且墙钟 ≤ 对照 120%；
- **失败也是产出**：若 qwen 驱不动工具（空转/乱查/超轮），原始数据直接成为模型路由（能力声明制）的实证输入——"agency 能力"成为 Phase B/C 判分步的声明项。

**A.4 白名单**：`server/tender/doc_pipeline.py`（落盘钩子）、新增 `server/tender/corpus_materialize.py`、`server/tender/runner.py`（工具面开关，≤15 行）、`.claude/commands/tender-evaluate.md`（三句）、hook 一处。禁触预算三件套与检索层。

### 纠偏令二 · vision-page 进入 D1 修复梯首位

D1 的预判（云 OCR 对盖章证书页返回空 → `pipeline.py:314` 静默跳过）方向正确，但修复梯（run_seal / 提 DPI / 换引擎）**全是换姿势转写**。关键事实：6 项 unresolved 中的供应商实力 / 业绩 / 团队人员**正是扫描证书页**——摄取产出空文本，检索必然召回不到。**D1 与 D2 在这几项上是同一病灶，转写修得再好也只是把图片降维成有损文字再去检索。**

**处置修订**：D1 实验"云 OCR 返回空"分支的首选修复改为 **vision-page 判定时刻问答**；转写增强降为次选（仅当 vision 端点不可用）。

**工具规格**：`.claude/skills/vision-page/vision.py`，仿 ocr-page 形态。入参 `(文件, 页, 问题)`，复用 `page_render_worker` 渲染 + `vlm_client` 带图提问，返回纯文本答案；PreToolUse hook 同款路径白名单。命令层接线：A2（读不清）的升级路径改为 vision-page 优先；证书有效期 / 公章归属 / 大写金额 / 检测报告标识类判定，指示优先带图问而非采信 OCR 文字。`pipeline.py:314` 的可观测量（"回填 N 页其中 M 页返回空"）照 plan 补，不因本令取消。

**度量**：证书类三项（实力/业绩/人员）的判出率，进回归闸对比表。
