## 二、缺口归因表增列（v2.1 二分表 → 四列，建议收编）

列A（文本可达，agency 应治）/ 列B（像素必需，vision 应治）照旧。本次双跑证实两个表外形态：

- **列C · 混合页（标题文本 + 图像正文）**：p315/316/345-348/372-375。页清单按字符数判 kind 会记成 text 页；检索命中的是**标题回声**（标题恰是投标人照抄的招标原文措辞），模型拿到章节名却零证据正文——比整页图更危险，因为它伪装成"已命中"。**修**：manifest 增列 `image_area_ratio`（`pdfimages -list` 每页图面积/页面积），`chars < 阈` **或** `ratio > 阈` → 该页判定强制走 vision；OCR 底稿在混合页落显式占位标记「本页正文为图像」，让 A3 与 A8 在文本上可分。
- **列D · 摄取管线（office 原生损失）**：招标 .doc 走"转 PDF → OCR"把评分表序号 2 行打坏，S1 残废级联全链。**修**：office 文件 **native 优先**（soffice → docx → 结构化提取，表格走原生 XML），OCR 仅兜底真扫描件。评分表是表格；OCR 表格重建永远劣于原生读取。Fable 侧 .doc→docx→文本零损失，是本次业绩项 9/9 与本地"规则无法识别"的全部差异来源。

## 三、行为移植的六个机制（回答"除了 skills 和工具调用还有什么"）

Fable 行为的可移植内核 = **判定驱动的升级阶梯 + 跨文件假设检验 + 确定性核对不进模型**。逐个给落点：

**1. 确定性核对下沉代码（facts_precheck 扩三项）——最便宜、最先做**

- 金额三处勾稽：regex 扫"合计/小写/大写"三处并互验；开标一览表是图页抽不到时，**自动登记一条 vision 任务**（这本身就是 D1"摄取期回填 vs 判定期问答"的路由判据，不用再单独实验）。
- 制造商覆盖核对：中小企业声明函制造商集合 ⊇ 报价明细品牌集合，差集直接注入（本案最高价值发现，属两表确定性比对，不该单点依赖模型）。
- 隐藏无效标触发点登记：承诺函 / 常规参数负偏离 / 付款方式三处（分别藏在需求正文、格式章注记、合同章）——代码侧扫触发词并把所在页注入，与 S1 触发词兜底互为校验。
- 原则：**模型不为确定性算术承担概率风险**。

**2. 升级阶梯进契约，不进散文**

- pending 项 schema 强制 `attempted[]: [{tool, target, result}]`；回查闸新增规则：`manual_review` 且 `attempted` 为空 → 打回。
- 这是裁决①"已找到什么/缺什么/查过哪里"三段义务的**机器可验版**。行为不是被提示词说服出来的，是被契约验收出来的——本地报告 7 项待核里没有一项记录过"试过什么工具"，因为没有东西强迫它试。
- 回查闸补一刀（治"p349 空白"这类断言错误）：对"空白/未提供/未定位"类否定断言，抽该页 chars 反证——页面有 3000 字却被断言空白，直接标 `claim_mismatch`。

**3. 工具面 + 轮次 = Step 5 本体，预算有实证**

- `TENDER_AGENCY=1`（Grep/Read 锁 corpus）+ vision-page 进判定流；per-item 升级预算：每 pending 项 ≤3 次调用（grep → Read → vision），全局 `max_turns ≈ 待核项数×3 + 10` 动态。
- 本次试跑实测：400 页 / ≈35 次工具调用 / 渲染 15 页（3.75%）/ 全部判定闭环——**预算可控不是猜测是数字**。列B 项的判出不需要全量 OCR 重跑，只需要判定时刻对的那一页。

**4. 示教注入（trace few-shot，弱模型的杠杆）**

- 把本轮两段真实调用序列压缩成 ≤60 行示例放 `tender-eval` skill 的 `references/exemplar-escalation.md`（SDK 按需加载不占常驻）：①"声明函 p12 → 起疑 → grep 品牌列 → 逐行归属 → 差集记 ambiguity"；②"证书页文本只有标题 → 渲染 → 三个一问一答（单位名/等级/有效期）→ 判分"。
- 弱模型对协议散文不敏感、对示例序列敏感；20K 字命令已到散文上限（criteria 回显占输出 60% 的教训同源），增量要走示例不走段落。

**5. 金标准 case-4（本案沉淀，先于一切改动落盘）**

- 预埋 8 判定点：大小写勾稽（图页）/ 制造商矛盾 / 营收雷同 / 常规 0 正偏离 / CS2 等级语义（数字升序，与建筑资质降序相反；CS 等级命名口径**待验证**）/ 检测依据链（安全标准封面 + 企业技术要求实测页两跳）/ 混合页证书判出 / 投标有效期缺席（电子标 confirmed:false 口径）。
- 回归闸新增列：**pending 项 attempted 覆盖率**（与 v2.1 已定的补证调用数、结论字节数并列）。
- 锚页规范照 v2.1"锚在证据实际页"金标准：p5/p7/p12/p315/p316/p345-348/p349/p361/p364/p369/p376。

**6. 能力声明制补一行（诚实边界）**

- "判定期内联视觉 + 长程规划"是**模型能力不是 harness 能力**：文本模型永远做不到本轮"边看图边推理"；vision-page 工具化是桥，桥的吞吐（一页一问一调）决定像素判定上限。
- 路由表增声明：图页+混合页占比 >15% 的单（本案 81+16/400 ≈ 24%），声明需 VLM-in-loop 或接受该部分 manual 兜底——别让文本模型档背像素债。
- 检测报告类判定写明**三跳协议**：封面（依据标准+型号+机构+章）→ 项目汇总页（企业技术要求在列否）→ 数据页（目标参数实测值）；vision-page 支持 `--pages N-M` 或命令层写明按跳三问。
