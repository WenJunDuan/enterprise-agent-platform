# S1 定位线索与排除

用于 `/tender-evaluate` S1 与 `/tender-extract-info` 步骤 1，定位本项目资格审查、初步评审与评分标准。招标文件 `criteria` 是项目评分唯一权威。

## 定位优先级

1. 先找最高优先级的资格/初步审查规则，再找评分表。
2. 资格规则常见标题：资格审查、资格性审查、资格评审、初步评审、符合性审查、响应性评审、资格审查证明文件。
3. 评分标准通常由评分表承载，常见列名：序号、评分点名称、评审标准、最高分、最低分、主客观分、评分项、分值、权重。
4. 章节标题含开标、评标、评审、商务技术标、报价标，也可能是评分标准来源；不限于《评标办法》字样。
5. 本类标书常把资格评审和评分表放在「第 X 部分 开标和评标」或第三章前附表，以实际招标文件结构为准。

## 关键排除

1. 详细评分标准是评标委员会对投标文件打分用的商务技术、报价等评分项，合计应等于满分。
2. 资格审查是并列的前置招标项，只进 `eligibility_rules[]`，不计入 `total_max`。
3. 必须排除中标后的考核方案、考核指标、季度考核、绩效考核、履约考核、KPI 表。
4. 上述履约阶段表常挂在附件或考核方案中，也可能列分值；误取会让整套 `criteria` 取错。

## 定位后自检

1. 评分 `items[].max` 之和必须等于 `total_max`，例如 70 + 30 = 100。
2. 资格审查不得参与满分合计。
3. 对不上时视为漏取或取错表，必须回到招标文件重新定位。
